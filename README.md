# The Word You'd Delete From the Dictionary

One word, erased from the dictionary forever — written by a pure-stdlib Python program for the make.fun bounty **The Word You'd Delete From the Dictionary**.

> synergy

Delete it and no meeting, memo, or middle manager can ever say it again. Corporate speak loses its flagship empty word — the gap it leaves is the joke.

Run `python3 main.py` — it writes the word (one word, 7 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–77 characters, exactly one word, no surrounding whitespace).
